# Responsive HTML Email Templates

HTML email examples designed for desktop and mobile, targeting Gmail, Outlook, Apple Mail, and other email clients. Templates use table-based layouts, inline CSS, and Outlook compatibility techniques.

## Templates

- [OTP verification](otp-verification.html)
- [Registration welcome](registration-welcome.html)
- [Transaction receipt](transaction-receipt.html)
- [Marketing campaign](marketing-campaign.html)
- [Newsletter](newsletter.html)

## Usage

Open any HTML file in a browser to preview. Replace sample branding, content, credentials, and links, then import into a sending platform such as ClickDimensions. Update both HTML and Outlook button URLs, and insert actual platform unsubscribe links where applicable.

No dependencies or build step required. Examples use fictional data. Email-client rendering and platform imports have not yet been tested; send test emails before production use.
